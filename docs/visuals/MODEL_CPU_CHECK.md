# 可重复的模型 CPU 几何检查

在工作区运行：

```powershell
node scripts/check-models.mjs
```

需要当前项目已安装的Node 24与依赖。脚本自行读取三个内容目录的Markdown，不依赖可能过期的dist快照，也不会执行同步、构建、浏览器操作或网络访问。唯一测试输出为`artifacts/model-verification.json`；失败时仍写报告，并以非零退出码结束。

## 调用的真实入口

| 站点 | 实际调用 |
|---|---|
| 空间 | `space/src/models.js`的`createObject(entry)`、`animateObject(model, delta)` |
| 时间 | `time/src/subjects.js`的`timeSubjects[entry.visual.scene](invalidate, entry)` |
| 温度 | `energy/src/subjects.js`的`thermalSubjects[entry.visual.scene](invalidate, entry)` |

不直接绕过这些入口去调用通用模板，避免入口没有注册、精选覆盖未生效却得到假通过。缺失visual同步、未注册场景、通用模板配置与实际模板不一致，都会失败。

有限值包含合法的0，例如大爆炸时间零点与绝对零度；空间长度必须大于0。null条目逐条记录`modelBuilt:false`，不调用构造函数；若仍有场景配置则报告覆盖错误。

## 检查内容

- 对每个有限量值，构造实际THREE.Group，并在累计0、1、10、60秒检查模型。两检查点之间用30帧/秒的delta推进，保留依赖delta的旧精选动画，不用一次60秒大步长代替。
- 检查全部几何属性、morph属性、索引范围、实例变换矩阵、世界矩阵以及常用材质和shader uniform数值的有限性。
- 包围盒使用真实CPU顶点和变换计算，要求非空、有限。演示模型采用最大边长0.0001–200、中心各轴绝对值不超过100世界单位的宽松异常拦截范围；这不是摄像机取景合格标准。
- 全部空间自定义模型（72通用+4精选覆盖）必须具有reference。声明长度、本地端点实际间距、根变换后的世界端点间距均为2；轴、kind、framePadding与测量口径必须一致。
- 专门防止已发现的口径退化：DNA初始横宽必须为2；海王星外轨道直径必须为2；核点云示意的rms距离必须为2而非直径；普通/约化康普顿图形的相位跨度分别为2π/1弧度。
- 统计逐条构造结果、模板使用数、几何顶点、可绘制对象、实例数、四个时间点的包围盒、来源输入哈希和失败堆栈。若检查过程中输入变化，测试失败，要求基于稳定输入重跑。

输入哈希覆盖三个内容目录与实际模型、模板、映射及共享渲染辅助模块。新增条目会自动进入范围；不通过硬编码“257条”掩盖遗漏。当前内容基线为285条，其中257条有限、28条null。

## CPU环境模拟的边界

Node24模块解析hooks仅将`/engine/*`映射到本地真实`engine/packages/*`。Three的材质、几何、曲线、矩阵、BufferGeometry和包围盒计算都使用项目真实依赖，没有替换成假模型。

只模拟模型构造所必需的浏览器设施：

- Canvas 2D与渐变对象：绘图为空操作，文本宽度按字号和字符数近似计算；报告记录Canvas、文字和方法调用次数。
- EventTarget：支持纹理资源池的事件和pagehide释放路径。
- fetch：只允许读取`content/assets`内实际本地媒体，以及工作区内明确的file URL JSON；绝不调用Node原生fetch，不允许外部HTTP请求。
- ImageBitmap：读取本地PNG/JPEG真实文件头宽高，但不解码像素；模拟close并统计释放次数。
- 1440×900、devicePixelRatio=1的固定视口变量：仅供模型构造参数使用，不创建窗口或页面。

不支持的访问、缺失本地纹理或位图文件头错误都会写进失败报告。模拟文字、Canvas和位图只用于CPU构造可执行性，不能据此宣称标签清晰或图片质量合格。
