## 实际产物

- 291 个门户与知识静态页，另保留空间、时间、温度探索页与说明页。
- 285 篇文章有稳定 URL，正文在构建时写入 HTML，不依赖客户端渲染。
- 轻量 catalog.json 用于搜索；content-snapshot.json 与 build-report.json 可追溯内容。
- 搜索覆盖名称、英文名、分类和摘要，精确名称排在摘要匹配之前；URL 保留搜索与分类状态。
- 三条探索路线、贡献说明与关于页面已经先行建设；公开贡献通道明确显示尚未建立。
- 404 页面已生成；serve.mjs 增加 404 HTML 响应，服务器代码更新需重启服务生效。

## 验证结果

构建与自动校验通过：285 篇文章、5,576 个本地 href / src、搜索排序和维度过滤、确定性快照、数值边界及源码语法。一次性迁移校验确认 285 条旧数据的数值、摘要和正文保留。

浏览器实测：桌面首页；390 × 844 手机首页、知识库、地球文章；手机文章跳转空间 / 时间 / 温度的准确 ID；旧根路径 object / scale 分享链接兼容。检查范围未发现横向溢出。搜索“地球”73 条，时间维度24条，空结果与清除交互正常。

这些结果不代表完成了所有设备、性能指标和科学审核。当前仍有 285 条缺少科学来源，3 条时间记录越界；时间和温度专属图景配置共 17 条，其余参考图景与空间占位模型继续按 M4 扩展。
