# 元素轴（elements.）建设计划

版本：2026-11-08 · 计划稿（第一步交付，未开工）· 基线：内容 v1.0.5 / 引擎 v0.3.1 / 1,070 条（空间 527、时间 300、温度 243）

本计划只定义元素轴怎么做、做多少、怎么验收，不改动仓库。元素轴按用户要求采用“层级跃迁”结构，不做 118 张平铺卡片。

## 1. 轴的定义与判据

元素轴的单位不是千克、米或秒，而是 **质子数 Z**：从 Z=1 到 Z=118。每增加一个质子，原子核多一个正电荷，核外电子必须按壳层重新填入；填满一层、开始下一层、核内中子数偏离稳定线，都会造成性质跃变。

因此元素轴是**有序但非连续的层级轴**：

- 坐标是整数 Z（1–118），不是可无限细分的连续量。
- 骨架节点是闭壳层：2、10、18、36、54、86、118。
- 惰性气体是“这一层讲完”，碱金属是“下一层重新开始”。
- 过渡系、镧系、锕系是“壳层交错填充”的插入段，不是线性排列的例外。
- 同一元素的不同单质（石墨/金刚石、氧气/臭氧）不是不同轴条目；元素页讲元素，同素异形体放在解释层。
- 元素质量、密度、熔点等性质不是轴读数；它们作为元素的结构化属性存在，不替代 Z。

### 1.1 每条元素条目的最低判据

| 字段 | 要求 |
| --- | --- |
| `id` | `elements.{小写元素符号}`，如 `elements.fe`、`elements.og` |
| `dimension` | `element` |
| `quantity` | `value` = Z（整数 1–118），`unit` = `Z`，`measure` = “原子序数（质子数）” |
| 身份 | 符号、中文名、英文名、周期、族、区块（s/p/d/f） |
| 结构 | 基态电子排布、价电子构型 |
| 相对 Z−1 | 第一电离能、原子半径、电负性、价电子变化、N/Z、来源变化 |
| 核 | 稳定同位素数、放射性/半衰期、衰变方式 |
| 来源 | 大爆炸/恒星/s/r/p/散裂/人工，至少一个过程标签 |
| 来源文献 | 至少 2 条；A 级 3 条 |
| 正文 | 450–800 汉字（A 级 800–1,200），5 个 `##` 小节 |

## 2. 骨架：七次闭壳，七次重新开始

| 周期 | Z | 填充顺序 | 闭壳节点 | 起点元素 | 元素数 | 质变说明 |
| --- | --- | --- | --- | --- | --- | --- |
| P1 | 1–2 | 1s | He (2) | H | 2 | 1s 填满；第一个惰性气体；H/He 丰度由大爆炸决定 |
| P2 | 3–10 | 2s→2p | Ne (10) | Li | 8 | 2s 开始，价电子从 1 到 8；Li 低电离能，F 高电负性 |
| P3 | 11–18 | 3s→3p | Ar (18) | Na | 8 | 3s 重新开始；3d 未填，为 P4 的 4s 先填埋下伏笔 |
| P4 | 19–36 | 4s→3d→4p | Kr (36) | K | 18 | 4s 先于 3d；K/Ca 是“新层开始”，Sc–Zn 是第一次过渡系 |
| P5 | 37–54 | 5s→4d→5p | Xe (54) | Rb | 18 | 5s 重新开始；4d 过渡系；Ag/Cd 等 d10s2 特殊构型 |
| P6 | 55–86 | 6s→4f→5d→6p | Rn (86) | Cs | 32 | 6s 开始；La–Lu 填 4f，镧系收缩；Hg 的 6s 相对论效应 |
| P7 | 87–118 | 7s→5f→6d→7p | Og (118) | Fr | 32 | 7s 开始；Ac–Lr 填 5f；Z≥104 为人工超重元素，Og 闭壳为预测 |

七个闭壳节点单独成页（可与周期 hub 合并），每页回答“这一层为什么在这里结束、下一层为什么从这里开始”。碱金属节点（Li、Na、K、Rb、Cs、Fr）明确写“新壳层的第一颗电子”。

## 3. 每个元素页必须回答的七件事

元素页不是“元素百科卡片”，而是“相对前一个元素，发生了什么”的对照页。每页固定包含：

| 区块 | 必须回答 | 数据来源/呈现 |
| --- | --- | --- |
| 01 身份 | Z、符号、名称、周期、族、区块 | 表头 + 周期表位置 |
| 02 相对 Z−1 | 多了一个质子；电子进入哪个亚层；第一电离能 Δ；原子半径 Δ；电负性 Δ；价电子构型 Δ | 构建期由相邻元素数据计算，生成对照条 |
| 03 电子排布 | 基态构型、价层、异常构型（Cr、Cu、Gd、Pt 等） | 构型字符串 + 能级示意 |
| 04 核稳定性 | 稳定同位素数、N/Z、放射性/半衰期、衰变方式、幻数 | 稳定性带图 + 数值 |
| 05 从哪来 | 大爆炸/恒星/s/r/p/散裂/人工；太阳系丰度 | 来源标签 + 时间轴锚点 |
| 06 为什么在这里 | 族/周期位置与性质的关系；闭壳或起点 | 解释层链接 |
| 07 常见误解 | 元素≠单质、Z≠质量数、稳定≠永恒、超重元素预测值 | 误解条目 + 交叉链接 |

“02 相对 Z−1”是硬性区块，不允许省略。对 Z=1 的氢，写“没有 Z−1”；对超重元素，写“预测值/未知”，但仍必须回答“多了什么、变了什么”。

## 6. 解释层、来源层与方法层

元素页回答“这一个”，解释层回答“为什么周期表长这样”，来源层回答“元素从哪来”。三层缺一不可。

### 6.1 解释层（6 页）

1. **电子排布与能级填充**：Aufbau 原理、n+l 规则、4s/3d 交错、Cr/Cu/Gd/Pt 异常。
2. **屏蔽与有效核电荷**：为什么同周期电离能上升、同族下降；Slater 规则只作定性。
3. **原子半径与电负性**：经验半径/共价半径/范德华半径不是同一口径；Pauling 电负性的定义与局限。
4. **镧系收缩与相对论效应**：4f 填充、6s 收缩、Hg 液态、Au 颜色、Pt 惰性。
5. **核稳定性、幻数与衰变**：N/Z、稳定线、幻数 2/8/20/28/50/82/126、α/β/γ/自发裂变。
6. **周期表为什么长这样**：从门捷列夫到量子力学；位置—构型—性质的三段关系。

### 6.2 来源层（8 页）

| 过程 | 代表元素 | 现有时间锚点 | 缺口/动作 |
| --- | --- | --- | --- |
| 大爆炸核合成 | H、He、Li | `time.big-bang`、`time.nucleosynthesis`、`time.lithium-7-synthesis`、`time.deuterium-bottleneck` | 已有，直接挂接 |
| 恒星核合成/CNO | C、N、O、Ne、Mg、Si | `time.first-stars` | 已有，补元素页链接 |
| 三α过程与铁峰 | Fe、Ni、Co | `time.pop-iii-supernovae`、`time.heavy-element-enrichment` | 已有，补链 |
| s 过程 | Sr、Y、Zr、Ba、La、Ce、Pb、Bi | `time.heavy-element-enrichment` | 缺 AGB 阶段锚点，计划新增 `time.agb-phase` |
| r 过程 | Eu、Gd、Au、Pt、U、Th | 无直接节点 | 计划新增 `time.neutron-star-merger` |
| p 过程与宇宙线散裂 | Li、Be、B、稀有富质子同位素 | `time.first-stars`（间接） | 缺散裂锚点，解释层说明 |
| 人工合成与超重元素 | Tc、Pm、Np、Pu、Am、Cm、Z≥93 | 无直接节点 | 计划新增 `time.nuclear-age` |
| 太阳系元素丰度 | 全部稳定元素 | `time.solar-system`、`time.earth-formation` | 已有，补丰度表 |

新增的 3 个时间节点属于 E7 批次的支撑内容，不改变时间轴现有 300 条的主体；若评审不同意新增，r 过程与人工合成两页降级为“解释页内嵌时间锚点”。三个新增节点也要走同样的来源与校验流程。

### 6.3 方法层（3 页）

- 原子半径怎么量：X 射线/电子衍射、经验半径与共价半径的差异。
- 电离能怎么量：光谱、光电子能谱；第一电离能与逐级电离能。
- 同位素与半衰期怎么定：质谱、衰变计数、宇宙成因核素。

## 7. 口径与风险处置

| 风险 | 典型表现 | 处置 |
| --- | --- | --- |
| 把 Z 当连续刻度 | 用对数轴或“Z 越大越重”代替结构 | 站点用周期/壳层骨架；Z 只作整数坐标；不用 log10 |
| 元素≠单质 | 把“铁元素”写成“铁块” | 元素页讲元素；单质、合金、同素异形体放解释层或独立条目 |
| Z≠质量数 | 用原子质量代替 Z | `quantity.value` 只能是 Z；质量数、同位素质量进 `element.isotopes` |
| 同位素混淆 | 把某种同位素的性质写成元素通性 | 元素页给稳定同位素范围；具体同位素另设数据字段/条目 |
| “稳定”定义 | 把观测稳定当成绝对稳定 | 区分 primordial/observationally stable/radioactive；半衰期标注 |
| 超重元素预测 | 把预测构型/半径当成实测 | `predicted: true`；未知值写 `null` + 原因；不伪造精确值 |
| 中文名/符号不一致 | 生僻字无法显示、IUPAC 新旧符号混用 | 以 IUPAC 现行符号为准；中文生僻字提供符号回退；页面同时显示符号 |
| 周期表异常被抹平 | 4s/3d、镧系收缩被写成“例外” | 在解释层正面解释；元素页写实际构型 |
| 核合成来源过度归因 | 把某元素唯一归给 s 或 r 过程 | 允许多标签；标注模型依赖；丰度数据给出来源 |
| 原子半径口径混用 | 共价半径与范德华半径直接比较 | `measure` 必填；同族/同周期比较只用同一口径 |
| 电负性尺度混用 | Pauling 与 Mulliken 数值直接比 | 存 `scale` 字段；跨尺度不比较 |

## 8. 图景与可视化方案

元素轴的首屏必须先是“壳层阶梯”，再是周期表。周期表是导航地图，不是 118 张卡片墙。

1. **壳层阶梯**：七级台阶，标注 1s/2s2p/3s3p/4s3d4p/5s4d5p/6s4f5d6p/7s5f6d7p；每级显示容量与实际填充数；闭壳节点发光，碱金属节点显示“新层开始”。
2. **周期表地图**：标准 18 族布局；颜色按区块（s/p/d/f）；点击格子进入元素页；闭壳列（18 族）与碱金属列（1 族）有固定图例；不把周期表做成无限滚动的卡片列表。
3. **Z−1→Z 对照面板**：选中元素后，左侧显示 Z−1，右侧显示 Z；中间显示“多了一个质子，电子进入 3d/4s…”，并列出 ΔIE、Δ半径、Δ电负性、Δ价电子、ΔN/Z。
4. **核稳定性带**：N（中子数）对 Z 的散点；稳定同位素、β 衰变、α 衰变、自发裂变区域；点击进入元素页。
5. **来源丝带**：按大爆炸/恒星/s/r/p/散裂/人工着色；与时间轴节点双向链接。
6. **3D 壳层动画（可选）**：电子按亚层填入的示意；默认静态 SVG，WebGL 只作增强；`prefers-reduced-motion` 关闭动画；移动端用纵向壳层列表。
7. **OG/首屏**：`elements` 站单独 1200×630 分享图；首屏文字构建期写入；无 JS 也能读到“118 个元素、7 次闭壳”。

设计验收硬线：首屏出现壳层阶梯与周期表地图；不允许首屏就是 118 个等权卡片；任意元素页都能在两次点击内到达 Z−1 与 Z+1。

## 9. 数据模型改动

元素轴沿用单 `quantity`，新增一个可选的 `element` 结构化对象；不把多种性质塞进 `quantity`。

```yaml
id: elements.fe
dimension: element
quantity:
  value: 26
  unit: Z
  measure: 原子序数（质子数）
  approximate: false
element:
  symbol: Fe
  nameEn: Iron
  period: 4
  group: 8
  block: d
  configuration: '[Ar] 3d6 4s2'
  valence: '3d6 4s2'
  ionizationEnergy: {value: 7.9024, unit: eV, measure: 第一电离能}
  atomicRadius: {value: 126, unit: pm, measure: 经验半径}
  electronegativity: {value: 1.83, scale: Pauling}
  stability: {status: stable, stableIsotopes: 4, isotopes: 26}
  origin: [stellar, s-process, r-process]
  abundance: {solar: 3.16e-5, unit: relative-to-Si}
```

### 9.2 站点形态

- `elements` 站是单页探索器：读取 `entries.json`（118 条），渲染壳层阶梯、周期表、Z−1→Z 对照、稳定性带、来源丝带。

## 11. 校验与验收标准

每一批完成后必须全过：

1. `npm run build`：1,070 + 新增条目；sitemap 覆盖元素页。
2. `npm run check`：链接、搜索、路由、站点隔离。
3. `npm run check:content -- --gate`：schema、来源、正文、related。
4. `npm run check:migration`：旧 ID 不误删。
5. `npm run check:models`：元素站不要求 3D 模型时明确跳过；不得把 elements 条目误判为 space。
6. `npm run release:local` + `npm run check:release`：新增站点进发布包，站点隔离仍成立。
7. `node scripts/check-learning.mjs`：学习层引用 0 悬空。
