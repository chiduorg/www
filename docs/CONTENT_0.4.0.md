## 具体改变

- 从“数值和维护说明”扩展为“是什么、怎样知道、比较口径、常见误解、知识联系”。52篇均为4—5个有实质内容的小节，正文约414—562个汉字（不含小节标题；字数仅作记录，不作为准确性或质量证明）。
- 每个事实段落通过`[n]`连接本条sources。更新后的52篇共有140条文章来源记录；同一主源可以被多篇采用，不将其称为140个独立来源。
- 增加可复算的缩尺与温标例子、观测/实验方法、模型推断和证据适用范围。例如月球篇把自身大小与地月距离分开；太阳核心篇解释日震和中微子为何是不同约束；寒武纪篇把纪界、化石记录与演化过程分开。
- 28条量值未定的文章提供实际知识，不再主要围绕“旧数字撤下”展开。编辑缺口及旧值保留在简短末节或review记录。
- 补充有解释价值的related关联。只深化正文与来源，不改变现有quantity、displayValue、chronology、visual、canonicalId、审核状态及旧量值证据。水的冰点补充与空气接触的条件，使说明与所引实验相符。
