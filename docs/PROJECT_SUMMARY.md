## 1 项目是什么

「尺度 MAGNITUDE」是一个由 Markdown 内容源派生的开放知识站：门户负责总览与检索，五个量纲站各自承担一个尺度的浏览与比较。

- 门户：`chidu.org` —— 首页、知识库、规模总表、学习层、路线、挑战、关于。
- 空间 `space.chidu.org`：长度与大小比较，527 条。
- 时间 `time.chidu.org`：宇宙时间与事件年代，303 条。
- 温度 `temperature.chidu.org`：K / °C 与极端温区，243 条。
- 元素 `elements.chidu.org`：118 个元素位 + 闭壳层与解释页，135 条。
- 质量 `mass.chidu.org`：146 条，B1–B16 质量阶梯。
- 共享资产 `static.chidu.org`：three.js、OG 图、媒体图、favicon，五轴共用一份。

工程上分八仓：`content`、`engine`、`home`、`space`、`time`、`temperature`、`elements`、`mass`。各站锁定内容与引擎版本、独立构建，运行时不依赖中央服务。

品牌「尺度 MAGNITUDE」仍是工作名，`brandStatus: working`，未最终定名。

## 8 边界与限制

- `reviewed` 是限定范围的来源与口径核对，不是外部同行评审。
- 外部来源站对自动请求返回 Cloudflare/reCAPTCHA；有头浏览器可读 Britannica，RSC/PubChem 数据需交互，未逐页重读全文。
- 3D 图景、颜色与运动是解释性示意，不是物理仿真或观测重建。
- 模型检查是 CPU 全量，不等同于逐场景 GPU 视觉验收。
- Lighthouse 与 FPS 是本机 localhost 样本，不是手机或公网指标承诺。
- 50 条未定量值是刻意保留，不承诺全部转为可比较数值。
- 中英切换覆盖 UI、导航、页脚、按钮、舞台标题、文章标题与侧栏标签；文章正文、摘要和部分质量轴标题仍是中文，完整英文正文需要单独内容翻译工程。
- 浅色主题已有「浅色 3D 舞台 + 浅色 chrome/知识层」的完整分支；默认仍是深色舞台，切换后统一跟随页面主题。
- 移动端顶部主导航在 ≤700px 收起，链接统一进入固定 8 项底栏；底栏占 56px，页面底部留出安全区与 8px 页脚间距。701px 起恢复顶部 7 项主导航，“导航”仍是最后一 项。
- 顶部“共同构建”入口与独立“学习”入口已移除；`/contribute/` 与 `/learning/` 页面本身仍保留，前者作为联系与修订说明页，后者作为首页学习区的延伸阅读。
- 当前工作区没有 Git 版本控制，源码历史依赖本地备份与文档记录。
