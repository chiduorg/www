## 它是什么

石英是 SiO₂ 的结晶相，α-石英由共顶点的 SiO₄ 四面体组成三维骨架。[1] 本页量的 4.91 Å 是六方晶胞的 a 轴长度，即晶胞参数，不是手标本尺寸，也不是 Si—O 键长。[2] 每个硅原子被四个氧原子包围成 SiO₄ 四面体，四面体通过共顶点氧连成三维骨架，沿 c 轴方向留出六方通道。[1] α-石英没有对称中心，因此具有压电性；它的两种手性结构分别对应 P3₁21 与 P3₂21 空间群。[2]

## 怎样知道

X 射线粉末与单晶精修给出 α-石英的六方晶胞：a = 4.9135 Å、c = 5.4050 Å，Z = 3，空间群 P3₁21 或 P3₂21。[1] 独立整理的矿物学数据同样列出 a = 4.9133 Å、c = 5.4053 Å。[2] 两者一致到小数点后三位。粉末衍射还给出 Z = 3 与晶胞体积；结合 SiO₂ 的摩尔质量和实测密度约 2.65 g/cm³，可以反算每个晶胞的含硅量，与结构模型自洽。[1] 这种交叉检验说明晶胞参数不是单一测量的孤证。

## 数值与口径

4.91 Å 等于 4.91×10⁻¹⁰ m、0.491 nm。口径是晶胞 a 轴，不是 c 轴 5.405 Å，也不是整块石英晶体（可从毫米到米）。[1] 它更不是 Si—O 键长约 1.61 Å；一个晶胞里包含多个四面体。六方晶胞体积约为 113 Å³，a 轴与 c 轴之比约 0.91。这里的 a 轴是六方底面内的重复距离，c 轴是沿通道方向的重复距离，两者方向不同。[1][2] 数值为常温常压下的 α-石英相。

## 常见误解

常见误解之一是把晶胞参数当成手标本尺寸；石英晶体可以长到几十厘米，而晶胞只有 0.5 nm。[2] 另一个误解是把 a 轴与 c 轴对调；两者分别是 4.91 Å 和 5.41 Å。[1] 还有人把石英玻璃的无序网络当成晶体，玻璃没有这样的长程周期。也有人把石英晶体的六方柱面宽度当成 a 轴；柱面宽度是宏观晶习，可达厘米，而 a 轴只是晶胞内部的重复周期。[2] 此外，高温的 β-石英对称性不同，不能直接套用这组参数。

## 与其他尺度的关系

0.491 nm 约为 NaCl 晶格常数 0.564 nm 的 0.87 倍，约为金刚石晶胞 0.357 nm 的 1.4 倍。[1][2] 它比苯环大 1.75 倍，却仍远小于一个细胞。与 Si—O 键长约 0.161 nm 相比，a 轴约为其 3 倍；与方解石 a 轴 0.499 nm 相比则几乎相等。[1][2] 这些比较说明不同硅酸盐与碳酸盐的晶胞底面可以落在同一尺度。继续阅读晶格间距、NaCl 晶体与金刚石晶胞，可比较不同晶体结构的晶胞参数。
