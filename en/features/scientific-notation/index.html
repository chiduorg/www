Scientific notation: how to read a×10ⁿ

Machine-assisted draft · native review pending

The scientific numeric is written in 1≤a<10 and 10, which allows comparison, multiplication and retention of signatures. The calculator E is just another writing.

A x 10n

Scientific representation is a x 10n, of which 1 ≤|10, n is the integer. 0.0001 m in 1×10⁻⁶; 6,371,000 m in6.371×10⁶. If the coefficients are retained, then the number is trusted. [1][2] A negative index is not a “negative”, but a penultimate:10⁻³= 0.001. The reading of10⁻³as "negative three thousand" is a common error; the index only describes the direction and digits of decimal points. [1][5]

Conversion and Operations

The multiplier multiplys the coefficient, the index is added, the coefficient is divided and the index is reduced. Adds or subtracts are to be combined with the same index;10²cannot be added directly to10³. [1][6] In units, the index follows the unit. 1 km2=10⁶m2, not 10³; 1 cm3=10⁻⁶. The area and volume index multiplied by 2 or 3. [1][5]

Scientific mode separates “significant figures” from “order of magnitude”:6.371×10⁶has four significant figures, 6.4×10⁶ only two. It's written as6.371000×10⁶, implying precision that the instrument does not support. [2] [4] The number of tails given by the calculator is not equal to significant figures. Calculator and E

The calculator displays 1.23E-05, meaning1.23×10⁻⁵, not a negative five-sided calculation of 1.23. E is only the abbreviation "x10" and is read with the scientific log. It cannot make uncertainty smaller, nor can it make approximation an exact value; it still has to be written where the word “about” is written.
