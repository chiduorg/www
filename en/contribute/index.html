Corrections are welcome: a wrong unit, an unsupported claim, a mistranslated term, a sentence that reads unnaturally.

01 / Name the entry and the source

Use the stable entry title and the source number shown in the article. Quote the sentence that needs correction; do not send a whole-page rewrite without a reason.

02 / Separate facts from style

A fact correction needs a citable source. A style correction needs a proposed replacement and, ideally, a glossary note. Both are useful; they are reviewed differently.

03 / Check the Chinese original

The English page is downstream of the Chinese entry. If the Chinese source is wrong, fix the Chinese entry first; otherwise the English page will inherit the error.

04 / Run the local checks

Content changes must pass the content and feature audits, the English audit and a full build before status changes. Unreviewed changes stay labelled as drafts.
