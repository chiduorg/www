What's the value?

This value is3.844×10^07m, obtained from the base reading "Earth to Moon Distance"3.844×10^08m times 0.1. The base entry measure is the average half-axis of Moon orbiting the Earth; conversion does not change the physical object, it changes only on which scale we put it. [1]

How's that?

The calculation is subject to gradual review:3.844×10^08m x 0.1 =3.844×10^07m. If the base value is replaced by another unit and the same multiplier is applied, the result must return to the same order of mass; the unit, the multiplier and the signatureficant figures must be recorded together, and not leave only one number. Why keep this anchor?

This anchor is used to connect "Earth to Moon" to neighbouring intestry: when the reader asks "What it feels like to be bigger/smaller", it is possible to provide this article directly without recalculating it. It is suitable for the contrast position of the scale steps, combinations or object pages. [3]

With the neighbor scale.

Line this article with the Earth (12742000 m); Moon (347800 m) to see first whether the unit is uniform, then whether the comparator is in diameter, radius or or orbit distance; the same number may be twice or more different under the same series. The baseline entry summary provides a readable starting point: the NASAMoon fact sheet gives an orbital half-axis of about 384,400 km. This page uses it as a reference to the Earth's moon distance; the Moon orbit is not a positive circle, so the actual Earth's heart-to-heart distance changes with the orbital position. [1][3]

How does Error pass it?

Error follows the baseline entry: the base value significant figures determine the results of the conversion; the multiplier is a precise integer or simple fraction and does not add to the measurementor. [1][2] If the baseline value itself is a approximation, the limitation of “approximate” should be retained thereafter.

Mass

Moon

Moon is the only natural satellite of the Earth, with a total mass of about 7.346×10²² kg, or about one-one-first point of the Earth. The laser moon follows the Moon orbiter and gives about 0.01 per cent relative to uncertainty, which is one of the most accurate measurements in the body mass.
