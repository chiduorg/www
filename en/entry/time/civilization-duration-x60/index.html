What's the value?

The value of this article is9.467×10^12s, obtained from the base reading of 1.578×10^11 s times 60. The base sum is a continuous time of civilization recorded as textual; selection is disputed for 5,000 years; conversion does not change the physical object, it changes the level on which we place it. [1]

How's that?

The calculation is subject to gradual review:1.578×10^11s x 60 =9.467×10^12s. If the base value is replaced by another unit and the same multiplier is applied, the result must return to the same order of mass; the unit, the multiplier and the signatureficant figures must be recorded together, and not leave only one number. This anchor is used to connect "civilization continuity" to neighbouring intestry: when the reader asks "What does it feel like to be bigger/smaller?", it can be directly related to this article without having to recalculate. It is suitable for the contrast position of the scale steps, combinations or object pages. [3]
