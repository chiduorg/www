2.000×10^11K, based on the 1.000×10^11 of "core collapse microballs" and x2 conversion, is used to connect the adjacent scale anchor, not the new independent measurement.

What's the value?

The value of this article is2.000×10^11K, which is obtained by multiplying the base reading of 1.000×10^11K by 2. The baseline entry measure is the radiation of the neutron microball on the surface of the original neutron; conversion does not change the physical object, it changes the layer on which we put it on scale. [1]

How's that?

The calculation is subject to gradual review:1.000×10^11K x 2 =2.000×10^11K. If the base value is replaced by another unit and the same multiplier is applied, the result must return to the same order of mass; the unit, the multiplier and the signatureficant figures must be recorded together, and not leave only one number. [2]

Why keep this anchor?

This anchor is used to connect the "core collapse temperature" to the adjacent intestry: when the reader asks, "What does it feel like to be bigger/smaller?", the article can be directly defined without having to be recalculated. It is suitable for the contrast position of the scale steps, combinations or object pages. [3]

With the neighbor scale.

When this article is lined up with the core collapse supernova thermometer (10,000,000 K); the core of neutron (required for cooling model) (None K), see first whether the unit is unified and then whether the comparator is in diameter, radius or orbital distance; the same number may be twice or more different under the same series. The base entry sumary provides a readable starting point: the neutron ball on the surface of the original neutron star is about 10 MeV, or10¹¹K. It describes thermal radiation of the last dispersion surface of neutrinos, which is not even at the core of the collapse. [1][3]

How does Error pass it?

Error follows the baseline entry: the base value significant figures determine the results of the conversion; the multiplier is a precise integer or simple fraction and does not add to the measurementor. [1][2] If the baseline value itself is a approximation, the limitation of “approximate” should be retained thereafter.
