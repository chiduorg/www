## 它是什么

软 X 射线是 X 射线中波长较长、光子能量较低的一段，位于极紫外与硬 X 射线之间。[1][2] 本条量的是真空中的波长，不是管电压、剂量或穿透深度。10纳米是该段长波端的示例，与极紫外相邻；它仍属于电离辐射。“软”描述的是光子能量相对较低，而不是“非电离”。

## 怎样知道

Britannica 把 X 射线总范围写作约10纳米至0.01纳米，对应光子能量约100电子伏至1兆电子伏。[1] 同一百科的 X 射线基本特性页在应用部分说明，软 X 射线通常指1至10纳米，并利用其在水与生物样品中的穿透差异成像。[2] 两处口径一致：10纳米正是软 X 射线的长波端。同步辐射与X射线激光可提供高亮度的软X射线，用于表面与材料分析。[2]

## 数值与口径

10纳米等于1×10⁻⁸米，也写作0.01微米；按真空光速换算，对应约3×10¹⁶赫兹，光子能量约124电子伏。[1][2] 它比1纳米代表值的X射线长10倍，比可见光紫端400纳米短40倍。比较软 X 射线数据时，要说明是波长、光子能量还是曝光量，三者不能互换。

## 常见误解

把“软”理解为“没有危害”是危险的误解：软 X 射线能量较低，但仍能使原子电离。[1] 另一个误解是把它与极紫外等同；两者在10纳米附近相接，但产生机制与探测方式不同。也不能用波长直接判断医学风险，剂量、照射时间与组织吸收同样重要。

## 与其他尺度的关系

10纳米约为可见光紫端400纳米的1/40，也比硬 X 射线常用的1纳米长10倍。[1][2] 软 X 射线位于极紫外与硬 X 射线之间，适合研究原子尺度结构、表面与生物样品；它在大气中衰减很快，观测与实验常需真空或太空环境。它与极紫外的分界也随资料变化，10纳米附近既有重叠也有不同的探测手段。
