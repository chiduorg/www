# Universe Atlas engine

共用能力仓，不是中央在线服务。当前版本0.3.0，以一个本地可分发包提供独立ESM入口；站点按需采用模块，并锁定包版本、内容快照和tarball完整性。

| 模块 | 所有权与作用 |
|---|---|
| packages/content | 内容校验、来源与未定量值约束、编译/确定性快照、路由、阅读口径 |
| packages/quantities | 单位、数量级、线性比例与范围计算 |
| packages/renderer | 可选Three.js视口、按需/30FPS动画、隐藏暂停、指针输入、纹理加载与取消、资源释放 |
| packages/ui | 共用基础样式、品牌、章节/详情、审核/条件呈现与图文回退 |
| packages/build | 独立静态构建、跨站链接配置、固定快照校验、预览服务 |

空间、时间和温度的专属场景仍归各站。引擎不拥有具体科学条目，不强制所有站加载3D。门户生成静态正文，运行时只用检索等轻量模块。

使用npm ci、npm run check。站点导出包内含固定engine/content tarball和package-lock，各站可独立npm ci、npm run build，不借用兄弟目录的源码或依赖。

浏览器纹理资源池按URL缓存。页面离开（不进入bfcache）和WebGL上下文丢失会中止请求并释放位图；主动图文模式不创建WebGL视口。隐藏页面停止连续渲染；手动操作仍可按需绘制。复杂模型是否等比例、温度是否代表实测等知识判断属于内容与站点。

0.3.0为本地建设版本；远程包发布和公共许可证尚未配置。后续可依据真实升级节奏进一步拆分NPM包，当前ESM入口已经按能力分开，避免因抽象数量增加维护负担。
