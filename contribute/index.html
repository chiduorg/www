贡献通道建设中

开源远程仓库尚未建立，当前可以下载条目原文并在本地准备修改。公开仓库建立后将接入 Issue 和 Pull Request 入口。

01 / 找到具体条目

从知识库打开文章，记录稳定的条目 ID，并通过“查看 Markdown 原文”获取当前内容。修改正文不改变现有 ID。

02 / 补充可以核实的依据

说明要修改的具体事实、数值、单位或口径，并附权威机构、原始论文或正式资料的链接、标题与访问日期。理论推断与实测结果分别说明。

03 / 提交图景与素材

模型和图片需要来源及许可证。列明画面中的示意、比例夸张和不能准确模拟的部分；提供静态回退与减少动态方案。

04 / 本地校验

在内容目录修改 Markdown，执行项目的 build 和 check 命令。审核通过后再变更状态；未经核实的记录保持“待审核”。
