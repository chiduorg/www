绝对零度与负温度：0 K 不是“没有热”

Absolute zero and negative temperature: 0 K is not 'no heat'

编辑性来源核对·8 分钟阅读

0 K 是热力学允许的最低温度，不是粒子完全静止。负温度也不是“比 0 K 更冷”，而是在特定系统中比正无穷温度更热的状态。

0 K 不是“没有热”

绝对零度是 0 K，约 −273.15 °C。按经典图像，温度对应分子平均动能；到了 0 K，热运动似乎应该完全停止。[1][4]

量子力学不允许这样。即使在最低能态，粒子仍有零点能；位置与动量不能同时为零。液氦在极低温下仍保持量子流体行为，超流氦可以无粘滞地流动，正是零点能与凝聚态相互作用的体现。[4][5]

所以 0 K 更准确的说法是：系统处于最低可能能态，不能再通过降温把能量取走。 不是“什么都没有”，而是“没有可再提取的热”。

为什么达不到 0 K

热力学第三定律说，有限步骤无法把系统冷却到 0 K。每降一步，散热越来越难；接近 0 K 时，热容趋近于零，任何微小热泄漏都会把温度抬回去。[1][2]

实验室能做到毫开尔文甚至更低的等效自旋温度，但“达到 0 K”不是工程难度问题，而是热力学极限。我们只能无限接近，不能抵达。[2][3]

稀释制冷机怎么工作

稀释制冷机利用氦-3 与氦-4 的混合—相分离：在极低温下，氦-3 从稀释相进入浓缩相时吸热，把周围环境冷却。多级预冷后，混合室可以达到毫开尔文量级。[3]

它不是“把热量抽到负温度”，而是用相平衡与熵变搬运热量。PLTS-2000 等温标为 0.9 mK 到 1 K 的范围提供校准，说明这段温区已经有可复现的计量体系。[3]

负温度是什么

负温度不是“比绝对零度更冷”。在热力学里，温度的定义与熵对能量的导数有关；对常规系统，温度为正。对某些具有能量上限的孤立系统（例如核自旋体系、部分光学晶格系统），粒子数反转可以让导数变负。[5]

负温度系统其实比任何正温度都热：热量会从负温度流向正温度。它不是“冷到负数”，而是“能量分布倒过来了”。[5]

玻色—爱因斯坦凝聚

当玻色子被冷却到临界温度以下，大量粒子占据同一个最低能态，形成玻色—爱因斯坦凝聚。它不是“原子停止运动”，而是波函数在宏观尺度上同相位。[5]

BEC 的观测需要极低温度与高度可控的陷阱；它把“温度”从单个粒子的平均动能，变成整个量子态的统计性质。这也是为什么 0 K 附近的物理不能用日常直觉外推。[5]

读温度刻度的方法

第一，看单位：K、mK、nK 不是同一个尺度。第二，看系统：电子温度、自旋温度、晶格温度可以不同，一个“负温度”标签必须说明是哪一种自由度。第三，看定义：负温度只在特定统计系统中成立，不是普遍的自然现象。[2][5]

把这些分开，才能理解为什么“0 K 不可达”和“负温度存在”并不矛盾：一个说的是热力学下限，一个说的是特定系统的能量分布。两者都不是“更冷”的同义词。[1][5][6]

毫开尔文下面还有什么

在稀释制冷机之外，还有激光冷却、蒸发冷却、绝热去磁和核自旋冷却。每一种方法对应不同的自由度：原子运动、电子自旋、核自旋。所谓“最低温度”往往只指某一种自由度，而不是整块材料的所有能量。[2][3]

例如，原子气体的平动温度可以低到纳开尔文，但内部电子态仍可能处于激发态；自旋温度可以更低，晶格温度却更高。读实验论文时，必须看温度计测的是哪一部分。[2][3]

这也是“负温度”实验容易引发误解的原因：它通常指自旋或粒子数分布的等效温度，不是整块样品的温度计读数。把等效温度当成日常温度，就会得出“比绝对零度更冷”的错误结论。[5][6]

温度计不是尺子

温度计测的是一个宏观平衡量，不是单个粒子的速度。红外测温读的是表面辐射，热电偶读的是接触点温度，气体温度计读的是分子平均动能；三者对同一个物体可以给出不同的数。[1][2]

在极低温下，热接触变弱、热容变小，温度计本身的热量就可能扰动样品。所谓“测到 100 mK”，需要说明测温方法、校准链和热锚，而不是只报一个数。[2][3]

温度 / 极低温

绝对零度

绝对零度是热力学温标的零点：0 K 等于 −273.15 °C。温度降到零不等于一切微观运动消失；量子零点运动不能用经典粒子的完全静止来表示。

玻色-爱因斯坦凝聚

1995 年的稀薄铷原子气体实验在约 170 nK 出现玻色–爱因斯坦凝聚。这里采用该实验的参考温度； 凝聚条件与原子种类、密度和阱参数有关，不能把它当作所有物质共有的固定温度。

约 170 nK（1.7 × 10⁻⁷ K）↗

稀释制冷

稀释制冷装置能够支持毫开尔文尺度实验。NIST 报道的一套扫描探针显微镜设施工作在约 10 mK； 这里采用这个具体装置示例，不宣称所有稀释制冷机或所有量子器件都需要同一温度。

氦-3 超流 A 点（PLTS-2000）

BIPM 的 PLTS-2000 把氦-3 熔化线上的超流 A 点列为 2.444 mK、3.43407 MPa。本条以这个明确温标固定点 代替无压力条件的 2.5 mK；它不是任意压力下氦-3 的统一转变温度。

温度 / 常温

人体体温

约 37 °C（310.15 K）是常用的体温参考值，而非每个人每时每刻都具有的精确温度。体温读数会随个体、时段和测量部位等因素变化。
