温度计与温标：0 度为什么不是“没有热”？

Thermometers and scales: why 0 °C is not “no heat”

编辑性来源核对·9 分钟阅读

温度计把不可见的冷热变成可读的数字，但数字依赖温标。摄氏、华氏与开尔文共享间隔，却有不同的零点；现代开尔文由玻尔兹曼常数定义。

先有温度计，后有温标

伽利略时代的测温器利用空气或液体随冷热膨胀，但没有统一刻度。1714 年，华伦海特用冰盐混合物、冰水与人体温度等固定点建立标度；1742 年，摄氏把冰点与沸点分成 100 格。[1] 这些温标先是操作工具，后来才被热力学解释。

摄氏与开尔文

摄氏温度 t 与开尔文 T 满足 t = T − 273.15；单位间隔相同，零点不同。0 ℃ 是标准大气压下的冰点，不是“没有热”；绝对零度 0 K 才是热力学温度的理论下限。[2] 把 20 ℃ 说成 10 ℃ 的“两倍热”是错误，因为摄氏零点有偏移。

热力学温度

开尔文最初由理想气体与卡诺循环定义，后来用水的三相点等固定点实现。2019 年起，开尔文由玻尔兹曼常数 k = 1.380649×10⁻²³ J/K 的固定值定义，温度测量变为能量标定。[3] 这使温度单位不再依赖一个具体水样。

实用温标

日常与工业测量使用 ITS-90 等国际温标：在固定点之间用铂电阻、热电偶、辐射温度计等内插。不同温区、不同传感器有不同不确定度；测表面温度、气温与核心温度不能用同一支温度计直接替代。[1][3]

常见误解

常见误解是“摄氏就是百分度，所以 0 ℃ 没有能量”。0 ℃ 的水仍有分子动能与潜热；相变时温度不变，能量却在改变。[2] 另一个误解是“开尔文只是摄氏加 273”；开尔文的零点与单位定义都不同，换算温差时不需要加偏移。

相变时温度为什么不变

冰水混合物在标准大气压下保持 0 ℃，继续加热时冰先融化，温度不上升；这部分能量用于破坏晶格，叫潜热。[1] 温度计读数是分子平均动能的指标，但相变时能量进入势能而不是动能，所以“加热”不等于“升温”。

体温、气温与表面温度

气温是百叶箱内空气的温度，体表温度受皮肤血流、出汗与辐射影响，红外测温读的是表面辐射亮温。[2] 三者不能用同一支温度计互换。发烧时额温可能低于核心温度；工业表面温度用辐射温度计还要知道发射率。

ITS-90 与不确定度

国际温标 ITS-90 在规定固定点之间用铂电阻、热电偶、辐射温度计等内插。不同温区有不同标准仪器与不确定度；校准链从国家计量院传到工厂与医院。[3] “温度计显示 37.0 ℃”背后有一整条溯源链，不是单个传感器。

绝对零度为什么达不到

热力学第三定律说，有限步骤无法把系统冷却到 0 K；激光冷却与蒸发冷却可以逼近纳开尔文甚至皮开尔文，但仍有量子零点能与残余热交换。[1][3] 0 K 是渐近线，不是可到达的房间。

温度计的历史

伽利略的温度计依赖空气膨胀，读数受气压影响；华伦海特用酒精与汞建立固定点；摄尔修斯最初把沸点定为 0、冰点定为 100，后来才翻转。[1] 温标不是自然常数，而是人类约定的坐标。

负温度不是比绝对零度更冷

在热力学中，负绝对温度描述粒子数反转的系统：熵随能量增加而减少，温度定义为负。它比任何正温度都“热”，因为热量会从负温系统流向正温系统。[2] 日常说的“零下 10 度”只是摄氏标度上的负值，不是负绝对温度。

体感温度与湿球温度

体感温度综合气温、湿度、风速与辐射；湿球温度用蒸发冷却达到的极限，接近人体散热能力。[3] 在湿热环境，35 ℃ 湿球温度接近人体无法靠出汗降温的阈值，这比干球温度更能描述热风险。

关键数字

  • 0 K = −273.15 ℃，是热力学温度的绝对零度。
  • 0 ℃ = 273.15 K；37 ℃ = 310.15 K。
  • 标准大气压下冰点 0 ℃、沸点 100 ℃。
  • 水的三相点约 0.01 ℃，是 ITS-90 的固定点之一。
  • 湿热环境中，35 ℃ 湿球温度接近人体散热极限。
  • 太阳表面约 5,800 K，核心约 1,500 万 K。
  • 宇宙微波背景约 2.725 K。
  • 实验室激光冷却可到纳开尔文甚至更低。

名词速查

  • 热力学温度：以绝对零度为起点的温度。
  • 潜热：相变时吸收或释放而不改变温度的能量。
  • 湿球温度：蒸发冷却达到的最低温度。
  • 发射率：物体表面辐射与同温黑体辐射之比。
  • ITS-90：国际温度标准，规定固定点与内插仪器。

一个常见的反例

“−10 ℃”不是负绝对温度。摄氏负值仍在正开尔文温标上；热力学负温度只出现在粒子数反转等特殊系统，而且比正温度更热。把两个“负”混为一谈，会误解热力学。

继续查证的方向

可查 BIPM 的 ITS-90 文档、WMO 湿球温度观测规范与 NIST 的温度校准链。做热风险判断时，优先看湿球温度与持续时间，而不是只看干球温度。

自测三问

  1. 为什么相变时温度不变？ 能量进入潜热，用于破坏或形成分子间结构，而不是增加平均动能。
  2. 摄氏与开尔文差什么？ 零点不同：0 K = −273.15 ℃；温度间隔相同，1 ℃ 变化等于 1 K 变化。
  3. 为什么湿球温度更危险？ 它接近人体靠出汗散热的上限；高湿时汗液难蒸发，核心温度会上升。

如果只记住一件事

温度是分子平均动能的度量，但相变、辐射与体感都不能只靠一个数字。读温度必须同时问：测什么、在哪测、什么湿度与风速。

把数字放回尺度

从 2.7 K 的宇宙微波背景到 1,500 万 K 的太阳核心，跨度约 7 个数量级；人类日常温度只占其中很窄的一段。

五个温标锚点

  • 绝对零度：0 K（−273.15 °C）。绝对零度是热力学温标的零点：0 K 等于 −273.15 °C。[4]
  • 水的冰点：约 273.15 K（0 °C）。标准大气压附近，冰与水的平衡温度约为 273.15 K（0 °C）。[5]
  • 水三相点：273.16 K（ITS-90；实温需不确定度）。水的三相点在 ITS-90 中赋值为 273.16 K，即 0.01 °C，对应压力 611.657 Pa。[6]
  • 水的沸点：约 373.15 K（100 °C）。在标准大气压附近，水约在 100 °C（373.15 K）沸腾。[7]
  • 人体体温：约 310.15 K（37 °C）。约 37 °C（310.15 K）是常用的体温参考值，而非每个人每时每刻都具有的精确温度。[8]

把锚点连成一条线

五个固定点从绝对零度到水的三相点、冰点、沸点和人体温度，构成温标的骨架。[4][5][6][7][8]

温标不是把温度计刻度随便等分。开尔文用热力学定义，ITS-90 用一组可复现的固定点与插值公式；三相点是单一温度，冰点受压力与溶解空气影响，沸点随气压变化，体温则是范围而不是常数。[4][5][6][7][8]

温度 / 极低温

绝对零度

绝对零度是热力学温标的零点：0 K 等于 −273.15 °C。温度降到零不等于一切微观运动消失；量子零点运动不能用经典粒子的完全静止来表示。

温度 / 常温

水的冰点

标准大气压附近，冰与水的平衡温度约为 273.15 K（0 °C）。这是带条件的相变参考值；精密测温需要考虑压力、成分和溶解气体，而非把所有水的冻结过程视为完全相同。

约 273.15 K（0 °C）↗
温度 / 常温

水三相点

水的三相点在 ITS-90 中赋值为 273.16 K，即 0.01 °C，对应压力 611.657 Pa。它是冰、液态水与水蒸气共存的参考状态；自 2019 年起，开尔文已改由玻尔兹曼常数定义。

273.16 K（ITS-90；实温需不确定度）↗
温度 / 常温

水的沸点

在标准大气压附近，水约在 100 °C（373.15 K）沸腾。沸点随压力变化：较低压力下会在较低温度沸腾，较高压力下则需要更高温度。

约 373.15 K（100 °C）↗
温度 / 常温

人体体温

约 37 °C（310.15 K）是常用的体温参考值，而非每个人每时每刻都具有的精确温度。体温读数会随个体、时段和测量部位等因素变化。
